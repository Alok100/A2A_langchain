## Doc coverage vs “everything”

The **architecture_online** flow matches the spec and the PDF:

- User validation (MCP), session + long-term memory, classify, route (read / policy Q&A / write).
- Write branch: draft_action_plan → policy + data reasoning → critic → decision_guardrails → clarify / HITL / approve / deny → execute → persist_audit_log → format.
- Explainability: every response has decision + why + policy_reference.

**Optional / “more detail” if you want it later:**

- **Prediction Agent** and **Sentiment Agent** (doc §2.5, §3) — not drawn as separate nodes; can be added as parallel branches after classify or before format.
- **ask_clarifying_question** — in spec; ensure the diagram shows it looping back to classify or draft.
- **Timesheet & Asset** (doc §8, §9) — same graph; domains are handled by intent (timesheet/asset) and data nodes; no separate diagram needed unless you want a “domain map” view.
- **Advanced A2A** (doc §4): Debate pattern, Simulation agent, Compliance agent — can be added as extra nodes when you implement those phases.

So: **architecture_online.png is complete for the main doc**; the list above is what you can add for “very detailed” or later phases.
